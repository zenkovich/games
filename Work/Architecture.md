# Zero Line — архитектура прототипа

## Слои

```
Assets/Bootstrap.scn ── "ui camera" (2D, fitted 540×960) + актор "Game"
   ├─ ZeroLineHost (C++)                       ← регистрирует JS-мост `Bridge` (работает и из редактора)
   └─ ScriptableComponent (Scripts/ZeroLine.js) ← корневой JS-компонент: грузит модули, создаёт ZL.game
        └─ ZL.Game                              ← раунд, таймер, указатель, очки, сейв
             ├─ ZL.Board      (логика поля, чистый JS, headless)
             ├─ ZL.BoardView  (плитки, линия, анимации)
             ├─ ZL.Hud        (счёт, таймер, полоса суммы, «+N»)
             └─ ZL.Popup      (Game Over, PLAY AGAIN)
```

## C++ (`Sources/Game/ZeroLine/`)

- `GameJsBridge.{h,cpp}` — глобальный JS-объект `Bridge`: курсор (`IsCursorDown`,
  `GetCursorX/Y` — мышь и тач одинаково, берётся любой нажатый курсор), размер экрана,
  фабрики виджетов из слоёв (`CreateLabel`, `CreateButton`, `CreateTile` — плитка с слоями
  `glow/pos/neg/zero/text`), хранилище лучшего счёта `SaveText/LoadText` (файл рядом с
  бинарником; в WebAssembly — `localStorage` через `EM_JS`), `RunScript` (модули),
  `Log`. Стилей `ui_style` в проекте нет — виджеты собираются вручную.
- `ZeroLineBootstrap.{h,cpp}` — сборка bootstrap-сцены кодом (камера + актор Game) и
  сохранение `Assets/Bootstrap.scn`. Сцену регенерирует headless-тест `ZeroLineScene`.
- `ZeroLineHost.{h,cpp}` — компонент на акторе Game; в `OnStart` регистрирует мост.
- `GameApplication.cpp` — окно 450×800, регистрация моста, загрузка собранной
  `Bootstrap.scn` (или сборка кодом на свежем чекауте).

## JS (`Assets/Scripts/`)

- `ZeroLine.js` — корневой компонент (класс по имени файла). Стартует лениво, когда
  `Bridge` уже зарегистрирован.
- `ZL_Core.js` — неймспейс `ZL`, конфиг (размеры, веса, тайминги анимаций), RNG
  (mulberry32, сидируемый для тестов), раскладка (`cellCenter`/`cellAt` с зоной
  попадания 0.42 клетки), хелперы сцены (`makeSprite/makeRect/makeLabel/makeButton/place`).
- `ZL_Board.js` — модель: генерация по весам с балансом знаков (`PositiveChance`),
  гарантия хода (`FindMove` — DFS по линиям 2..4, `EnsureSolvable` перегенерирует
  свежие клетки, в крайнем случае чинит одну), выбор (`Select` → `added/undo/ignored`),
  `Sum/IsReady`, `Commit` → `{removed, score, falls, spawns}` для анимации.
- `ZL_BoardView.js` — плитки-виджеты в пуле, `SetSelection` (скейл ×1.12, свечение,
  линия из повёрнутых прямоугольников + точки в стыках; белое → зелёное при READY),
  `PlayMove` (вспышка 0.1 с → схлопывание 0.12 с; выжившие падают с ускорением после
  паузы 0.14 с; новые влетают сверху, скрыты до старта). Ввод не блокируется — модель
  меняется мгновенно, анимируется только отображение.
- `ZL_Hud.js` — счёт с догоняющим счётчиком и пульсом, таймер (красный ≤10 с), полоса
  выражения `3 + -2 + -1 = 0` и статус `READY` / `SUM: +3` (состояние доступно и в
  headless для тестов), BEST, всплывающие `+N`.
- `ZL_Popup.js` — затемнение, панель, счёт/лучший (`NEW BEST!`), кнопка PLAY AGAIN.
- `ZL_Game.js` — состояния `playing/gameover`, `PointerDown/Move/Up` (между событиями
  путь сэмплируется с шагом ¼ клетки — быстрый свайп не перепрыгивает плитки),
  таймер 60 с, `EndGame` (отмена линии, блокировка ввода, сейв лучшего), `Restart`.

## Координаты

Логический экран 540×960, начало в центре, y вверх. Колонка 0 — левая, ряд 0 — нижний
(плитки падают к ряду 0). Клетка 92, плитка 82, центр поля y = −40. Курсор из моста
приходит в пикселях окна — делится на `min(w/540, h/960)`.

## Тесты

- `GameTests/ZeroLineBoardTests.cpp` — модель через `o2Scripts.Eval`: сценарии из ТЗ
  (1+−1, 3−2−1, 5−3, повторный выбор, диагональ, обвал/спавн, очки, бонус за 0,
  распределение и баланс знаков, проходимость 60 полей + 80 ходов подряд, ремонт
  непроходимого спавна).
- `GameTests/ZeroLineGameTests.cpp` — игра headless на bootstrap-сцене: драг и коммит,
  неудачный релиз, быстрый свайп, зазоры между плитками, таймер/блокировка ввода,
  отмена линии по таймауту, рестарт, сейв/лоад лучшего счёта.
- `GameTests/ZeroLineSceneTests.cpp` — регенерация `Assets/Bootstrap.scn` и загрузка.
- `GameUITests/ZeroLineUITests.cpp` — реальное окно и курсор через `AppTestDriver`:
  рендер поля, драг с суммой ≠ 0 и READY, удаление/падение/заполнение, неуспешный драг,
  Game Over и PLAY AGAIN. Скриншоты — `Work/ScreenShots/`.

## Ассеты

`Assets/ZeroLine/*.png` — сгенерированы процедурно `Work/Art/make_sprites.py` (PIL, 2×):
плитки трёх видов, свечение выделения, точка линии, пилюля, бейдж таймера, панель, кнопка,
подложка поля, фон. `Work/Art/compose_mockup.py` собирает из них статические мокапы
(`Work/Concepts/`) в тех же координатах, что и рантайм. Шрифт — M PLUS Rounded 1c (OFL).
