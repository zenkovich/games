# Word Fall — архитектура

## Слои

1. **C++ bootstrap** (`Sources/Game/WordFall/WordFallBootstrap.{h,cpp}`) — компонент по образцу
   DragonDefenseBootstrap: в `OnStart()` строит всю сцену кодом (слои, камера, фон, поле 7×8 из
   кнопок-плиток, HUD, панель слова, бустеры, попап), затем вешает `ScriptableComponent` с
   `Scripts/WordFallGame.js` на актор `Game`. Сохранённая сцена (`Assets/WordFall.scn`) содержит
   только актор Bootstrap — при загрузке из игры или редактора компонент строит всё сам
   (runtime path == editor path).
2. **JS модель** — `WordModel` (в WordFallGame.js, глобальный класс): чистая логика без движка —
   сетка, мешок, выбор, словарь, очки, гравитация, спавн, бустеры, состояние уровня.
   Тестируется headless через `o2Scripts`.
3. **JS вью-контроллер** — `WordFallGame extends o2.Component`: находит виджеты по путям,
   вешает `onClick`, мутирует тексты/цвета/слои, анимирует падение через `Update(dt)`.

Причина разбиения: из JS не доступны `o2Input`/`o2Scene`/`o2Assets`/создание шрифтов;
единственное JS-событие — `Button.onClick`. Поэтому весь визуал создаёт C++, JS только
мутирует готовые виджеты (SetText, color, enabled слоёв, layout-офсеты).

## Координаты

Окно 1280×800, центр (0,0), y вверх. Ячейка 68 px, плитка 64.
Центр плитки (c,r): `x = (c-3)*68`, `y = -20 + (r-3.5)*68` (r=0 — нижний ряд).
Поле: x ∈ [-204..204], y ∈ [-258..218]. HUD y=360, панель слова y=295, бустеры y=-350.

## Модель (WordModel)

- `grid[c][r] = { letter, value, ice, doubled, joker, powerup }`, 7×8;
  `powerup ∈ null|"bomb"|"rocket"|"wand"`.
- **Мешок**: 100 плиток с фиксированными частотами (GDD §6), тянется без возврата, перезаполняется.
  Анти-клин: если среди заполненных 8-соседей клетки спавна ≥2 букв и ни одной гласной —
  спавнится гласная (у каждой согласной есть гласная рядом, цепочки собираемы).
- **Выбор**: массив `selected[{c,r}]`, свободный по всему полю; повторный клик снимает
  букву и весь хвост после неё.
- **Очки**: `ceil(base × lenMult × clusterK)`, base = сумма номиналов (удвоитель ×2,
  джокер 0), lenMult = 1+0.25(L−3) при L>3, clusterK = размер максимальной связной
  компоненты выбранных плиток по 8-соседству (K≥2), иначе 1.
- **AcceptWord()**: валидация → очки слова → срабатывание пауэрапов на выбранных плитках
  (`_ActivatePowerups`: бомба — уничтожение 3×3 c очками; ракета — крест, палочка —
  одинаковые буквы: активация с очками и снятием льда, плитки остаются) → урон льду в
  8-соседстве слова (клетки, снесённые взрывом, пропускаются) → гравитация + спавн →
  прикрепление заработанного пауэрапа (5 букв — бомба, 6 — ракета, 7+ — палочка) к плитке
  на клетке последней буквы → обновление заданий → −1 ход → `_CheckWin` (очки ≥ цели И все
  задания) / lose. Возвращает объект результата (`gain`, `activated`, `powerupEarned`, ...)
  для анимации вью.
- **Задания** (`_tasks`, из `level.tasks`): `word` (матч с учётом джокеров), `length`
  (счётчик слов длины L), `powerup` (счётчик заработанных бонусов вида), `clearIce`
  (нет льда на поле; пересчёт и после молотка/взрывов), `anyWords` (счётчик любых слов),
  `wordScore` (слово стоимостью ≥ X). `NewGame` сидит одно случайное слово из
  `word`-заданий по случайным клеткам поля (`_SeedWord` — слово собираемо, но не
  лежит очевидной линией), лёд эти клетки обходит.
- **Страховка выполнимости** (`_EnsureTasksAchievable`, зовётся из NewGame/AcceptWord/
  молотка/перемешивания): при свободном выборе собираемость = мультинабор букв, поэтому
  проверки дешёвые (`_AnyWordExists` — первый матч префильтра). Невыполнимое задание
  чинится подсевом недостающих букв (`_PlantMissingLetters` в случайные клетки без льда
  и пауэрапов); для wordScore подсевается дорогое слово, при полном отсутствии слов —
  случайное короткое.
- **Уровни**: кампания из 100 процедурных уровней — `WordFallLevels.Get(index)`
  (детерминирован по индексу: рампа цели/ходов/льда, задания из пула, слова из частых
  букв; при clearIce льда ≤ 6). `WordFallConfig.level` — песочница без заданий для тестов.
- **Бустеры** (заряды в модели): Hammer(c,r) — снос плитки без хода + гравитация/спавн;
  Shuffle() — перестановка букв по не-ледяным клеткам; Hint() — самое дорогое слово
  (`FindBestWord`: отсев по глобальному кэшу счётчиков букв слова `WordDictNeeds`,
  жадный подбор плиток, опц. фильтр длины для задач); Joker(c,r) — буква→«?»,
  номинал 0, матчится с любой буквой; Doubler(c,r) — номинал ×2.
- Словарь: `WordDict` — 23 509 русских существительных 3–8 букв (корпус
  Harrix/Russian-Nouns, MIT; сырец — `Work/Dict/russian_nouns.txt`, генератор —
  `Work/Dict/make_dict.py`, словарь вписывается в WordFallGame.js одной строкой со
  сплитом при загрузке). Матчинг с джокерами посимвольно; `FindBestWord` сначала
  отсеивает несобираемые слова по счётчикам букв поля (дефицит > числа джокеров),
  жадный подбор — только для прошедших.
  Выигрываемость кампании закреплена бот-тестом (первым ходом — посеянное слово, молоток
  по льду, length-задачи словами нужной длины, иначе лучшее слово; 3 уровня × 3 сида).
- RNG: свой LCG с сидом (`WORDFALL_SEED` из глобала, если задан — для тестов).

## Вью-контроллер (WordFallGame)

- `OnStart`: `WordFall_instance = this` (доступ из тестов), поиск виджетов, `onClick` на
  56 плиток/кнопки/бустеры, `NewGame(levels[_levelIndex])`, полный `SyncAll()`.
- `SyncWord` — слово рисуется мини-плитками-слотами (буква + номинал), центрируются по
  панели; цвет букв = валидность (зелёный/коричневый/красный flash).
- Перелёт буквы: клик по плитке запускает флаер из пула (4 шт) по квадратичному безье
  (контрольная точка выше и сбоку) со smoothstep-изингом, размер интерполируется
  64→48 с «вспуханием» по дороге; слот открывается по приземлении. Отмена выбора,
  бустеры и принятие слова гасят полёты.
- Прогресс-бар очков: JS ресайзит `BarFill` через `GetLayout().SetOffsetMin/Max`
  (минимальная ширина 34px, чтобы не сжимать слайс).
- **Секвенсор эффектов** (`_Fx(delay, dur, apply, done)` + `_UpdateFx`): начисление
  очков — этапами: вспышки подтверждения на плитках слова, цифры по очереди летят по
  дугам в счётчик «+N» (свечение под цифрой, вспышка-влёт при прилёте), сумма
  накапливается, затем полная сумма с бонусами, пауза ~0.75с, итог летит в
  прогресс-бар, бар плавно дозаполняется. Обвал поля отложен (`_pendingCollapse`):
  буквы исчезают и новые сыплются только после разлёта всех цифр. Экранный счёт `_displayScore`
  отстаёт от модельного до конца последовательности; попап победы/поражения ждёт её
  окончания (`_pendingPopup`). Новый ход/рестарт мгновенно финализирует текущую
  последовательность (`_FinishScoreFx`). Эффекты пауэрапов: бомба — вспышка + мелкие
  отголоски на взорванных клетках, ракета — растущие крестом лучи с растворением,
  палочка — вспышка и звёзды на активированных буквах (фейды — через scriptable
  `transparency` слоя `img`).
- Панели HUD и панель слова глубже плиток (depth 15–18 против 10.x) — спавн-плитки
  при падении ныряют за них, а не пролетают поверх.
- Вдавливание кнопок: стейт `pressed` с мультитрековым `AnimationClip` — сдвиг
  `layout/offsetMin/Max` на 4px вниз + проявление слоя с тем же спрайтом,
  тонированным тёмным (затемнение по силуэту). Button сам включает стейт при
  нажатии. У плиток сдвига нет (layout анимирует JS при падении) — только затемнение.
  `AddPressedState` зовётся после `SetWidgetRect`: треки сдвига захватывают офсеты.
- `_levelIndex` — текущий уровень кампании; кнопка попапа: победа → следующий уровень
  (после последнего — первый), поражение → рестарт. Заголовок/кнопка попапа меняются
  («УРОВЕНЬ ПРОЙДЕН!»/«ДАЛЬШЕ», «ИГРА ПРОЙДЕНА!»/«СНАЧАЛА», «ПОРАЖЕНИЕ»/«ЕЩЁ РАЗ»).
- `SyncTasks` — строки заданий с прогрессом, выполненные зелёные; `SyncTile` включает
  бейдж пауэрапа (слои bomb/rocket/wand).
- `Update(dt)`: анимация падения (экспоненциальное затухание визуального офсета к 0 через
  `GetLayout().SetOffsetMin/Max`), таймер «+N», сброс подсветки подсказки.
- Режим прицела бустера (молоток/джокер/удвоитель): клик по бустеру → `ModeLabel` текст,
  следующий клик по плитке применяет.
- Debug API для тестов: `DebugSetTile(c, r, letter)`, `DebugState()`.

## Тесты

- **GameTests/WordFallModelTests.cpp** — headless: `o2Scripts.Run(WordFallGame.js)` +
  `Eval` над `WordModel`: мешок и пропорции, выбор/отмена, валидация с джокером, кластерный
  множитель, подсчёт очков, гравитация и спавн, лёд, все 5 бустеров, победа/поражение.
- **GameUITests/WordFallUITests.cpp** — реальное окно: сцена через
  `WordFallBootstrap::CreateBootstrapActor()`, фиксированный сид + `DebugSetTile`,
  клики `AppTestDriver::Click` по координатам плиток, проверка модели через `Eval`,
  скриншоты в `Work/ScreenShots/`.

## Ассеты

`Assets/WordFall/Sprites/` — UI-арт по концепту `Work/Concepts/main_gameplay.png`,
произведён Gemini Nano Banana 2 (`o2/Tools/ImageGen`): бустеры/плитка/лёд/пилюля/бейдж —
`extract_region --part --transparent` из концепта (+точечные `edit_image`), крестик/рамка
выбора/пауэрапы/панели — `generate_transparent` с рефами на концепт. Сырьё в
`Work/Art/gen/`; механическая доводка (чистка альфы, кадрирование, сборка 9-slice,
pressed-варианты «затемнить+сдвинуть») — `Work/Art/process_ui.py` → `ui_*.png`:
ui_tile/ui_tile_sel/ui_tile_dim/ui_ice 160², ui_booster_*(+_pressed) 160²,
ui_btn_orange(+_pressed) 176×58 (slice 26/28/26/24), ui_btn_cross(+_pressed) 96²,
ui_panel_cream 96² (slice 28/30/28/26), ui_panel_board 120² (slice 36),
ui_bar_track 72×36, ui_bar_fill 72×30, ui_badge 72², powerup_bomb/rocket/wand 128².
Размеры слайсов подобраны под фактические размеры виджетов (границы не сжимаются).

Шрифт — `Assets/WordFall/game_font.ttf`: статический инстанс SF Compact Rounded wght=740
(fontTools varLib.instancer; системный шрифт Apple — для прототипа; в релизе заменить на
свободный аналог: Baloo 2 / Nunito ExtraBold).
`Assets/Scripts/WordFallGame.js` — скрипт игры. Ассеты собираются таргетом BuildAssets.
