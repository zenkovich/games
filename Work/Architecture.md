# Архитектура — Sahur’s Brain Farm

## Сцена и рендер

Мир Z-up, 100 юнитов = 1 м. `BrainFarmBootstrap` строит сцену API движка;
нативный тест сохраняет `Assets/Bootstrap.scn` для редактора. GLB-персонажи
имеют дочерний Visual с преобразованием из Y-up, статические OBJ экспортируются
сразу в Z-up. Персонаж сохраняет скелет из десяти костей и Idle/Run.

3D-камера: FOV 35°, наклон 45°, yaw 35°, near/far 10..10000. JS следует за
игроком с offset (1230, −1760, 2300). UI-камера вписывает 540×960.
В `DeferredPipeline` стандартный проход освещения заменён `FarmLightingPass`.
Он наследует ресурсы и uniform-параметры движка, подставляет GLSL/Metal fragment
shader с насыщенностью, контрастом и тёплым балансом. Дополнительного прохода и
render target нет. `Bridge.SetColorGrade(bool)` переключает коррекцию для A/B.

Иерархия:

- `Location`: остров 22×26 м, большой фон, объединённый декор, лавка на востоке.
- `Plantations/Plantation0..2`: грядка и 80 посадок, всего 240.
- `Player`: Visual и Stack; `Zombies`: очередь, клоны шаблона и уходящие покупатели.
- `CounterSpots`: 36 слотов; `Flights`: переносимые предметы.
- `BuyZones`: четыре последовательных улучшения; `Guide`: указатель цели.
- `HUD`: Image/Label/Button движка, джойстик с фиксированным основанием на время жеста и финальная кнопка.
- `Game`: ScriptableComponent с BrainFarm.js.

## Игровые модули

- `BF_Core`: конфиг, координаты, world/UI-преобразования и camera-relative ввод.
- `BF_Game`: экономика, выбор цели, локальный сбор, полёты, следование камеры.
- `BF_Player`: аналоговый джойстик, движение, столкновение с лавкой, анимация,
  стопка из двух или трёх колонок. Вместимость учитывает предметы в полёте.
- `BF_Plantations`: четыре столбца × двадцать рядов, ближайшее зрелое растение,
  координаты посадок берутся из мировых трансформов, учитывая поворот грядки,
  рост в 12 визуальных шагах. Зрелые растения статичны.
- `BF_Counter`: каскадная разгрузка и независимые слоты прилавка, продажа только
  после посадки. Предмет содержит actor, value и golden.
- `BF_Zombies`: очередь по восточной дороге, заказы 6/10/15, VIP-множители.
- `BF_Progression`: покупки 40/70/110/180, грядки, вместимость/скорость и рынок.
- `BF_Hud`: миссия, деньги, вместимость, ценники только в видимой части мира,
  указатель у края экрана, джойстик, монеты, toast и финал.

## Ресурсы и проверки

Baked vertex lighting выключен у мешей: освещение делает deferred-проход, без
повторного пересчёта геометрии между shadow/main pass. Brain LOD — 600 треугольников.
`FarmMeshComponent` кэширует world bounds для shadow pass и инвалидирует их при
изменении трансформа/меша. Это устраняет обход вершин 240 растений каждый кадр.
Меши вне frustum текущего прохода не отправляются на отрисовку; пересечение
проверяется консервативно по AABB, отдельно для камеры и shadow map.
Зрелые растения и неподвижная стопка не переписывают трансформы каждый кадр.
Blender запекает материалы/AO; Python уплотняет OBJ и PNG, проверяет открытые рёбра.
`Tools/build_sahur_web.py` строит host AssetBuilder и WASM Release, упаковывает
только игровые ресурсы и проверяет ZIP ≤5 000 000 байт.

`GameTests`: геометрия/размеры, локальность сбора, резервирование слотов, точные
цены, последовательные покупки и направления ввода. Headless bootstrap пропускает
визуальные ресурсы. `GameUITests`: рендер, shader A/B с pixel-difference, ввод,
продажа/финальная кнопка, JS bridge и 4800-кадровая нагрузка с контролем памяти.
`Tools/Browser/verify_sahur.cjs`: реальный ввод мышью без подмены денег/координат,
полная прогрессия, запись видео, screenshots, desktop и эмулированный touch.
