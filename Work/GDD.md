# Word Fall (Эрудит) — Game Design Document

## 1. Обзор

**Жанр:** пошаговая казуальная головоломка со словами (Scrabble × Match-3 × Тетрис).
**Платформа прототипа:** desktop (движок o2), окно 1280×800, управление мышью.
**Язык слов прототипа:** русский (словарь встроен в прототип).

**Суть:** игрок составляет слова из буквенных блоков на сетке. Составленное слово сгорает,
блоки над ним падают вниз (гравитация), сверху спавнятся новые буквы из сбалансированного
«мешка». Уровень имеет цель (набрать N очков) и лимит ходов.

## 2. Игровое поле

- Сетка **7×8** (7 колонок × 8 рядов) буквенных блоков.
- Каждый блок: буква + номинал очков (как в Скрэббле, в углу плитки).
- Блок может быть в состояниях: обычный, **лёд** (заморожен: нельзя выбрать, разбивается
  сгоранием соседнего слова), выбран.
- Выбор букв — **свободный по всему полю**: клик по плитке добавляет букву в конец
  текущего слова, повторный клик по выбранной — снимает её и все выбранные после неё.
  За компактный выбор начисляется кластерный бонус (см. §4).

## 3. Ход игры (core loop)

1. Игрок кликами набирает слово (панель текущего слова над полем).
2. Кнопка «Собрать» активна, если слово ≥ 2 букв и есть в словаре.
3. По нажатию: подсчёт очков → выбранные плитки сгорают (эффект) → соседние ледяные блоки
   получают урон → гравитация: блоки падают вниз → сверху досыпаются новые из «мешка».
4. Счётчик ходов −1. Проверка целей: очки ≥ цели → победа; ходы = 0 → поражение.

## 4. Подсчёт очков

- База: сумма номиналов букв слова (номиналы — по частотности русских букв, см. §6).
- Бонус длины: слово из L букв даёт множитель `1 + 0.25*(L-3)` при L>3 (4 буквы ×1.25, 5 ×1.5...).
- **Бонус компактности (Adjacency):** строится граф выбранных плиток, рёбра — соседство
  на поле по 8 направлениям (включая диагонали). Находится максимальный связный кластер
  размера K; множитель компактности = K (при K≥2). Разбросанные буквы — множитель 1.
- Итог: `очки = базовая_сумма × множитель_длины × множитель_кластера`, округление вверх.
- Плитка с бустером «Удвоитель» удваивает номинал своей буквы.

## 5. Мешок букв (сбалансированный спавн)

- Мешок — мультимножество букв с фиксированными пропорциями (частоты русского Скрэббла,
  урезанные до прототипа): гласные ~42%, согласные ~58%.
- Спавн тянет буквы из мешка без возврата; когда мешок пуст — перезаполняется заново.
- Гарантия под механику цепочек: если среди уже заполненных соседей клетки спавна
  (8 направлений) две и более букв и ни одной гласной — буква принудительно гласная.
  Так у каждой согласной есть гласная в соседстве и цепочки остаются собираемыми.

## 6. Номиналы и частоты (прототип)

| Буквы | Очки |
|---|---|
| О А Е И Н Т | 1 |
| С Р В Л К | 2 |
| М Д П У | 3 |
| Я Ы Ь Г З Б | 4 |
| Ч Й Х Ж Ш Ю Ц Щ Э Ф | 5 |
Мешок (100 плиток): О×9 А×8 Е×8 И×7 Н×6 Т×6 С×5 Р×5 В×4 Л×4 К×4 М×3 Д×3 П×3 У×3
Я×2 Ы×2 Ь×2 Г×2 З×2 Б×2 Ч×1 Й×1 Х×1 Ж×1 Ш×1 Ю×1 Ц×1 Щ×1 Э×1 Ф×1.

Буквы Ъ и Ё в прототип не входят: словарь прототипа не содержит слов с ними,
«мёртвые» буквы без слов только фрустрируют.

## 7. Уровни и система заданий

Кампания из **100 процедурно генерируемых уровней**: конфиг уровня детерминированно
строится по индексу (`WordFallLevels.Get(index)`) — цель по очкам, лимит ходов, лёд
и набор заданий растут по рампе сложности. **Очки — обязательное финальное условие:**
победа наступает только когда закрыты все задания И набрана цель по очкам.
Ходы кончились раньше — поражение.

Типы заданий (3–5 на уровень, генерируются из пула):
- **Точечное слово** (`word`) — собрать конкретное слово; слова подбираются из словаря
  (3–5 букв, только из частых букв — обиходная лексика); на уровне может быть и второе слово.
- **Категория по длине** (`length`) — собрать N слов из L букв.
- **Сбор бонусов** (`powerup`) — заработать пауэрап заданного вида (бомба/ракета/палочка;
  вид открывается по мере кампании).
- **Уничтожить препятствия** (`clearIce`) — разбить весь лёд (с этой задачей льда не
  больше 6: 3 молотка + разбивание словами).
- **Счётчик слов** (`anyWords`) — собрать N любых слов.
- **Дорогое слово** (`wordScore`) — собрать слово стоимостью ≥ X очков.

Первое задание всегда точечное слово — его буквы **разбрасываются по случайным
клеткам поля** при старте уровня: слово гарантированно собираемо, но не лежит
очевидной линией. Лёд на клетки сида не кладётся.

**Страховка выполнимости:** после каждого хода (и бустеров, меняющих поле) проверяется,
что каждое незакрытое задание достижимо: слово задания собираемо из букв поля, для
length/powerup существует слово нужной длины, для wordScore — достаточно дорогое.
Если нет — на поле подсеваются недостающие буквы (замена случайных плиток без льда
и пауэрапов), чтобы задания всегда оставались рабочими.

Рампа: цель ≈ 250 + 50 за каждые 10 уровней, ходы 12–16, льда 3–10.
Выигрываемость подтверждена ботом: 100 уровней × 3 набора сидов — 300/300 побед.

Попап финала: победа — «УРОВЕНЬ ПРОЙДЕН!» с кнопкой «ДАЛЬШЕ» (следующий уровень);
после сотого — «ИГРА ПРОЙДЕНА!» / «СНАЧАЛА»; поражение — «ПОРАЖЕНИЕ» / «ЕЩЁ РАЗ».

## 7a. Пауэрапы за длинные слова

За длинное слово на клетке его последней буквы появляется бонус, прикрепляющийся к
плитке, которая займёт эту клетку после падения. Срабатывает, когда игрок включает
эту плитку в новое собранное слово:

| Пауэрап | Условие | Эффект при срабатывании |
|---|---|---|
| 💣 Бомба | слово из 5 букв | Уничтожает 8 клеток вокруг себя (3×3, вместе со льдом); очки взорванных букв плюсуются к набранному |
| 🚀 Ракета | слово из 6 букв | Выстреливает крестом (вся строка + колонка): задетые буквы **активируются** — очки в счёт, лёд снят, сами остаются на поле |
| 🪄 Палочка | слово из 7+ букв | Активирует все такие же буквы по всему полю: очки в счёт, лёд снят, буквы остаются |

Очки от пауэрапов добавляются к очкам слова плоско (без множителей длины/кластера).
Плитка-носитель сгорает вместе со словом. Заработанные пауэрапы засчитываются в
задания типа «сбор бонусов».

## 8. Бустеры (по 3 заряда на уровень в прототипе; подсказка — 30)

| Бустер | Эффект |
|---|---|
| 🔨 Молоток | Клик по любой плитке — уничтожает её (и лёд) без траты хода, вызывает гравитацию+спавн |
| 🔀 Перемешивание | Все буквы на поле перетасовываются местами (состояния льда остаются на клетках) |
| 💡 Подсказка | Поиск самого дорогого доступного слова по словарю, подсветка его плиток |
| 🃏 Джокер | Клик по плитке — буква становится «?» (подходит как любая буква при проверке словаря), номинал 0 |
| ⬆️ Удвоитель | Клик по плитке — номинал буквы ×2 (значок на плитке) |

Режим бустера: клик по кнопке бустера включает «прицел» (у молотка/джокера/удвоителя),
следующий клик по плитке применяет; повторный клик по кнопке — отмена.

## 9. Словарь

Встроенный корпус: **23 509 русских существительных** 3–8 букв в начальной форме
(Harrix/Russian-Nouns, MIT; «ё»→«е», без слов с «ъ» — такой плитки нет в мешке).
Хранится строкой в скрипте игры, регенерация — `Work/Dict/make_dict.py`.
Проверка: точное совпадение с учётом джокеров («?» матчится с любой буквой).
Подсказка: быстрый отсев несобираемых слов по счётчикам букв поля (с учётом
джокеров), затем жадный подбор плиток (дорогие первыми), оценка очков, выбор максимума.

## 10. UI / экраны

- **Игровой экран:** сверху панель с номером уровня, прогресс-баром очков («31/250»)
  и боксом ходов; панель слова — набранные буквы отображаются мини-плитками с
  номиналами (буква перелетает с поля в панель по дуге), кнопка «Принять» и
  кнопка-крестик сброса; поле 7×8 на коричневой подложке; слева панель «Задачи»
  (до 5 строк с прогрессом, выполненные — зелёные); снизу панель бустеров
  (5 круглых кнопок, счётчик зарядов — бейдж сверху-справа). Пауэрап на плитке —
  иконка-бейдж в левом верхнем углу. Все кнопки визуально вдавливаются при нажатии.
  Начисление очков — поэтапное: на плитках слова играют вспышки подтверждения,
  цифры номиналов по очереди летят в счётчик (со свечением и вспышкой-влётом),
  сумма накапливается, после паузы итог летит в прогресс-бар; буквы исчезают и
  поле обваливается только после разлёта цифр. Срабатывания пауэрапов
  сопровождаются эффектами (вспышка бомбы, лучи ракеты, звёзды палочки).
- **Окно победы/поражения:** заголовок, итоговые очки, кнопка «Дальше»/«Сначала»/«Ещё раз».
- Стиль: тёплый casual, деревянные плитки с тиснёными буквами, мягкий фон.

## 11. Визуальный стиль

Уютный «настольный» casual: деревянные буквенные плитки со скруглениями, кремовый
фон-стол, сочные оранжево-янтарные акценты UI, мягкие тени. Ледяные блоки —
полупрозрачная голубая наледь поверх плитки.

## 12. Архитектура (кратко, детали в Architecture.md)

- Сцена `WordFall.scn` собирается кодом (bootstrap): камера, фон, поле, HUD, бустеры.
- Логика — JS (`ScriptableComponent`): `WordFallGame.js` — состояние поля, мешок,
  подсчёт очков, бустеры; отображение — акторы-плитки (спрайты + текст).
- Тесты: headless GameTests (логика: мешок, кластеры, очки, гравитация, словарь,
  бустеры) + GameUITests (клики по плиткам, скриншоты).
