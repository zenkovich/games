# Zero Line — гейм-дизайн документ

## Концепция

Мобильная аркадная головоломка на время. Поле 5×5 тайлов с целыми числами от −9 до 9.
Игрок проводит пальцем непрерывную линию по соседним тайлам (только вверх/вниз/влево/вправо);
когда сумма выбранных чисел равна 0 и палец отпущен — тайлы удаляются, начисляются очки,
верхние тайлы падают вниз, сверху появляются новые. Раунд — 60 секунд.

Core loop: найти сумму 0 → провести линию → удалить → получить очки → поле заполняется →
искать следующую комбинацию.

## Поле и числа

- Сетка 5×5, всегда полностью заполнена.
- Значения −9..9. Вероятность модуля (до нормализации):
  `9: 0.5, 8: 0.8, 7: 1.0, 6: 1.5, 5: 2.0, 4: 3.0, 3: 5.0, 2: 8.0, 1: 15.0, 0: 0.25`.
  Знак — 50/50, с мягким балансом: если на поле положительных заметно больше отрицательных
  (или наоборот), у новых тайлов знак смещается в сторону недостающего.
- Гарантия проходимости: после генерации поля и после каждого спавна проверяется, что
  существует хотя бы одна допустимая комбинация (путь из 2–4 соседних тайлов с суммой 0).
  Если нет — новые тайлы перегенерируются (до 30 попыток), в крайнем случае один из новых
  тайлов принудительно превращается в «ответ» для случайного соседа.

## Правила выбора

- Комбинация начинается касанием тайла и продолжается движением по соседним тайлам
  (4-соседство, без диагоналей).
- Тайл нельзя выбрать дважды в одной комбинации.
- Возврат пальца на предпоследний тайл снимает последний (undo) — стандартный UX line-draw
  игр, делает драг «прощающим».
- Минимум 2 тайла.
- Тайл добавляется сразу, как только палец пересёк его; между кадрами путь курсора
  сэмплируется, чтобы быстрый свайп не «перепрыгнул» тайл.
- Ввод: единый указатель (мышь на десктопе и первый палец на тач-устройствах — движок
  отдаёт их одинаково).

## Завершение комбинации

- Отпустил палец при сумме 0 и ≥2 тайлах → успех: тайлы удаляются, очки, обвал колонок,
  спавн новых сверху.
- Отпустил при сумме ≠ 0 → выделение снимается, поле не меняется.

## Очки

- `сумма |значений| удалённых тайлов × 10`; за каждый 0 в комбинации дополнительно +100.
  Примеры: `5, −3, −2` → 100; `4, −4` → 80; `3, 0, −3` → 60 + 100 = 160.
- Счёт отображается сверху, при начислении — всплывающий «+N» у комбинации и пульс счётчика.
- Лучший результат сохраняется между запусками (файл на десктопе, localStorage в web).

## Раунд

- 60 секунд, таймер сверху справа, последние 10 секунд подсвечиваются.
- На нуле: ввод блокируется, текущая комбинация отменяется, показывается экран Game Over:
  итоговый счёт, лучший счёт, кнопка PLAY AGAIN (полный сброс: поле, счёт, таймер).

## Интерфейс (логический экран 540×960, портрет)

```
┌──────────────────────────┐
│ SCORE               (47) │  ← лейбл + число слева, круглый таймер справа
│ 1240                     │
│  [ 3 + -2 + -1 = 0  READY ] │  ← полоса текущей суммы (во время драга)
│                          │
│      ┌────────────┐      │
│      │  5×5 поле  │      │  ← клетка 92, тайл 82, поле ~470×470 по центру
│      └────────────┘      │
│                          │
│         BEST 2310        │
└──────────────────────────┘
```

- Положительные — тёплые (коралл), отрицательные — холодные (голубой), 0 — золотой с
  сиянием. Крупные жирные цифры.
- Выбранный тайл увеличивается (×1.12) и получает светящуюся обводку; между выбранными
  тайлами — толстая линия со скруглёнными стыками. Пока сумма ≠ 0 — линия белая, обводка
  белая, полоса показывает `SUM: +3`; при сумме 0 — всё зелёное и `READY`.

## Визуальная обратная связь

- Успех: вспышка выбранных тайлов (~0.12 с) → схлопывание (~0.12 с) → падение остальных
  (ускоренное, ~0.25–0.35 с) → новые тайлы влетают сверху. Ввод не блокируется: логика
  поля обновляется мгновенно, анимируется только отображение.
- Неудача (сумма ≠ 0): выделение просто снимается.

## Вне scope

Никаких дополнительных механик (бустеров, комбо, уровней) — только core loop.
