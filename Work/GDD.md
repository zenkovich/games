# Color Town — GDD прототипа

Казуальный градостроитель без стресса: тактильный Collapse-«стакан» для добычи сырья, активная
экономика заказов, романтическая мета (Affinity) с персонажами одного пола (мужской каст,
otome-ниша). Прототип покрывает полный цикл: добыча → крафт → продажа → застройка → подарки/свидания.

## 1. Платформа и формат

- Портретный мобильный экран, дизайн-размер 1080×1920 (окно 540×960 на десктопе), тап — единственный
  ввод. Нет жизней, нет проигрыша, нет таймеров ожидания на Tier 1.

## 2. Игровой цикл

1. **Добыча (Core).** Игрок открывает здание Tier 1 → его личный «стакан» с 3 цветами шариков.
   Тап по шарику лопает всю группу одного цвета (≥2 соседей). Каждый шарик = 1 единица сырья
   (+бонусы). Стакан пополняется сверху непрерывно.
2. **Крафт (Orders).** В мастерской Tier 2 список заказов (рецептов). Тап «Сделать» забирает сырьё со
   склада, запускает короткий таймер (5–20 с), товар кладётся на склад.
3. **Продажа.** Товар продаётся со склада за `цена × множитель населения`.
4. **Застройка.** Монеты вкладываются в дома (население → множитель), декор (индекс красоты →
   условие для домов высших тиров, локации свиданий) и новые мастерские.
5. **Романтика (Meta).** Товары дарятся NPC (Affinity ↑), свидания в декор-локациях за премиум-подарок
   открывают сюжетные CG и пассивные баффы. Уровень Affinity — условие апгрейда здания NPC.

## 4. Склад и Overflow Conversion

Ёмкость склада на каждый вид — 30 (уровень 1), 60 (уровень 2, апгрейд 300 монет). Всё, что не влезло,
мгновенно конвертируется: 1 единица сырья → 1 монета + 1 XP города; 1 товар → 50% цены + 3 XP.
Игрок видит уведомление «Склад полон: +N монет». Тупика нет никогда.

## 5. Город: уровни и слоты

XP города даётся за продажу (10% цены), overflow и постройки. Уровень = порог XP (0/100/300/700/1500).
Слоты застройки открываются по уровню. Прототип: 4 здания Tier 1 стоят с самого начала;
6 свободных слотов для мастерских/домов/декора.

## 6. Affinity и свидания

4 NPC, шкала очков: уровни на 0 / 30 / 80 / 160 / 300 / 500 (0–5 «сердец»).
- Подарок: любой товар, +очки = цена товара / 2 (премиум ×1.5). Ограничение: 3 подарка подряд одного
  типа дают штраф −50% (разнообразие).
- Свидание: требуется премиум-товар + построенная локация (Парк/Кафе), даёт +40 очков и открывает
  сюжетную сцену (CG + 3 реплики). Каждому NPC — своя сцена для локации.
- Баффы: Affinity 3 — +15% добычи в стакане NPC; Affinity 5 — +10% к цене товаров из его сырья.

## 7. Экраны

1. **Город** — карта с домами, HUD (монеты, население/множитель, уровень города), кнопки Склад и
   Персонажи. Тап по зданию → его экран; тап по свободному слоту → меню постройки.
2. **Стакан** (Tier 1) — портрет NPC с сердцами, стакан с шариками, счётчики добытого, кнопка
   апгрейда, назад.
3. **Мастерская** (Tier 2) — список заказов с индикатором доступности и таймером, склад-строка.
4. **Склад** — окно со списком сырья/товаров, кнопки «Продать» у товаров, ёмкость и апгрейд.
5. **Персонаж** — портрет, шкала Affinity, «Подарить» (выбор товара), «Свидание» (выбор локации).
6. **Свидание** — CG-арт + диалоговые реплики, кнопка «Дальше».
7. **Постройка** — список доступных зданий для слота с ценой и условиями.

## 8. Ключевые ощущения

Zero-stress: всё доступно всегда, любое действие даёт награду, склад не блокирует, а «переливается»
в золото. Эмоциональный якорь — четыре персонажа, ради которых строится город.
