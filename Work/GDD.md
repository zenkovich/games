# GDD — «Картофельное Обби» (Potato Troll Obby)

## Концепция
Сложное тролль-обби (полоса препятствий в духе Roblox-обби) в 2D, вид сбоку. Герой — картофелина
Картофан. 30 уровней-экранов, каждый — путь от старта до мешка с картошкой. «Тролль» — уровни
обманывают игрока: блоки, которые падают или исчезают, невидимые платформы, фальшивые финиши,
подсказки, которые врут, зеркальное управление, переворот гравитации.

## Управление
- Клавиатура: ← → / A D — ходьба, Space / W / ↑ — прыжок (с койот-таймом 0.08 с и буфером 0.1 с).
- R — рестарт уровня. Esc — назад в меню.
- Тач/мышь: три экранные кнопки (влево, вправо, прыжок) внизу экрана.

## Экран
Логическое разрешение 1280×720, тайл 40 px → сетка 32×18. Уровень целиком помещается на экран,
камера неподвижна. Пол — нижний ряд сетки; падение ниже экрана = смерть.

## Физика
AABB-платформер: гравитация 2400 px/s², скорость 320 px/s, прыжок 800 px/s (≈3.3 тайла вверх,
дальность ≈ 5 тайлов). Тайловые коллизии по осям, прилипание к движущимся платформам.

## Типы тайлов (ASCII-карта уровня)
| Символ | Тайл | Поведение |
|---|---|---|
| `#` | Земляной блок | Твёрдый |
| `F` | Фальшивый блок | Выглядит как `#`; через 0.25 с после касания падает |
| `I` | Невидимый блок | Твёрдый, невидимый; проявляется после касания |
| `K` | Блок-мимик | Выглядит как `#`, убивает при касании |
| `D` | Мигающий блок | 1.4 с виден и твёрдый, 1.4 с исчезает |
| `V` | Пугливый блок | Исчезает, когда герой ближе 2 тайлов, возвращается через 2 с |
| `^` / `v` | Вилка (шип) вверх / вниз | Смерть |
| `M` / `N` | Движущаяся платформа гориз. / верт. | Ходит до препятствия и обратно |
| `B` | Батут | Выбрасывает вверх со скоростью 1250 |
| `<` / `>` | Конвейер | Сдвигает стоящего героя на 160 px/s |
| `G` | Переворот гравитации | Касание переворачивает гравитацию |
| `C` | Чекпоинт | Сохраняет точку возрождения |
| `T` | Фальшивый чекпоинт | Выглядит как `C`, телепортирует на старт |
| `S` | Старт | Точка появления |
| `E` | Мешок (финиш) | Победа |
| `X` | Фальшивый мешок | Выглядит как `E`, телепортирует на старт, тролль-сообщение |

## Уровневые флаги
`mirror` — зеркальное управление; `lowGravity`; `startFalls` — стартовая площадка рушится через
1 с; `exitRunsAway` — мешок отбегает на 3 тайла при первом приближении; `darkness` — виден только
круг вокруг героя; `hint` — подсказка на старте (иногда врёт).

## Прогресс
Счётчик смертей (за уровень и всего), таймер, номер уровня. Сохранение в `potato_obby_save.json`
рядом с исполняемым файлом (индекс открытого уровня, суммарные смерти). Главное меню: «Играть»,
выбор уровня из открытых. Финал после 30-го: «Ты — Картошка-Легенда», итоги.

## Кривая сложности
1–5: знакомство с одной механикой на уровень. 6–15: по две механики, первые ложные подсказки.
16–25: комбинации + зеркало/гравитация/темнота. 26–30: «ад»: мимики среди фальшивых, невидимые
маршруты, бегущий мешок, финальный уровень из всего сразу.

## Стиль
Яркий мультяшный вектор: деревенское поле, голубое небо, земляные блоки с травой, вилки-шипы,
мешковина финиша, герой — круглая картофелина с глазами и ручками.
