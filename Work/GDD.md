# GDD — «Sahur's Brain Farm» (рабочее название)

Демо мобильной игры в стиле stacking ad playable на движке o2. Полное 3D.

## Концепт

Персонаж (в духе «тум-тум-тум-сахур» — деревянный чудик с битой) бегает по ферме,
собирает мозги с плантаций, относит их к прилавку и продаёт зомби, стоящим в очереди.
На заработанные деньги открывает новые плантации.

Референс жанра: «My Mini Mart», «Farm Land» — arcade idle / stacking playable:
предметы визуально складываются в стопку за спиной персонажа, зоны покупки на полу,
всё управление — один виртуальный джойстик.

## Core loop

1. Мозги растут на плантациях (грядки, мозг «вырастает» скейлом из земли, созревший — покачивается).
2. Игрок подбегает — созревшие мозги по дуге перелетают в стопку за спиной (лимит стопки).
3. Игрок подходит к прилавку — мозги из стопки перелетают на прилавок (запас прилавка).
4. Зомби приходят с края локации, встают в очередь, по одному подходят, забирают мозг,
   платят деньги (летящая купюра в HUD), уходят.
5. На полу — зоны покупки с ценой: стоишь на зоне — деньги списываются, по заполнению
   открывается новая плантация.

## Управление

Виртуальный джойстик слева внизу: появляется под пальцем/курсором (в пределах левой
половины экрана), вектор отклонения — направление и скорость бега. Персонаж
поворачивается в сторону движения, анимации Idle/Run переключаются по скорости.

## Экран и HUD

- Портретная ориентация (~9:16), под мобильную рекламу.
- HUD: сверху — счётчик денег (иконка + число), казуальный стиль.
- Подсказки-маркеры: стрелка/иконка над созревшей плантацией и прилавком (опционально).

## Сцена (3D)

- Локация: лужайка-ферма, ограждение/декор по краям, casual low-poly.
- Плантации: 3 шт. (1 открыта со старта, 2 покупаются: например, 100$ и 250$).
  Каждая — грядка с 4 точками роста мозгов.
- Прилавок: стол/ларёк, рядом — точка сдачи для игрока и очередь зомби (4–5 мест).
- Камера: перспективная, смотрит сверху-сзади под ~50–60°, плавно следует за игроком.
- Свет: направленный «солнечный» + ambient, простые тени (shadow map движка,
  deferred pipeline; на слабых платформах — фолбэк без теней).

## Персонажи (3D, скиннед-анимации из GLB)

- Игрок: анимированный humanoid, клипы Idle / Run (+ опционально Carry).
- Зомби: анимированный humanoid-зомби, клипы Walk / Idle.

## Экономика (демо, финальные значения — BF.cfg в BF_Core.js)

- Цена мозга: 10$ за штуку.
- Стартовая плантация: 4 споты, рост 4 сек на мозг.
- Лимит стопки игрока: 8 мозгов.
- Запас прилавка: до 6 мозгов.
- Плантация #2 — 100$, плантация #3 — 250$ (списание 120$/сек стоя на зоне).
- Зомби приходят каждые 2.2 сек через калитку в заднем заборе, очередь до 5,
  покупка раз в 0.7 сек, один мозг на зомби.

## Технологии

- Движок o2: 3D-слой (перспективная CameraActor, SkinnedMeshComponent из .glb,
  Mesh3DComponent/.obj для статики, LightComponent + deferred pipeline с тенями),
  2D-слой для HUD (виджеты движка).
- Логика — JS (ScriptableComponent), сцена собирается кодом и сохраняется в .scn.
- Ассеты — свободные (CC0/CC-BY): анимированные GLB-персонажи, low-poly статика.
