# Space Evolver: Galaxy Core — GDD прототипа

Мобильный вертикальный 2D-шутер (vertical fly-and-shoot) с roguelite-элементами и мета-прогрессией.
Прототип на движке o2, портретная ориентация (окно 540×960), управление мышью/тачем.

## Core Loop

Забег на уровне → сбор орбов и монет → возврат в Ангар → прокачка → новый забег.
Эмоциональная цель — наглядный экспоненциальный рост силы: цифры урона на пушках, всплывающие
цифры урона, HP-плашки элитных врагов, «стены прогресса» из жирных врагов.

## Экран геймплея (In-Run)

### Управление
- Корабль закреплён на своей горизонтальной полосе: перетаскивание рулит только по X, вверх-вниз
  корабль не водится. Высота полосы зависит от указателя: под мышью — `cursorShipY`, под пальцем —
  `touchShipY` (ниже, чтобы корабль не оказывался далеко от пальца на телефоне). Смена полосы
  плавная (`laneLerpSpeed`).
- Тип указателя определяется по id курсора: мышь — всегда 0, касание получает id от браузера.
- Автострельба непрерывна, вверх по оси Y.

### Главный калибр (эволюция по внутриигровому уровню)
| Ур. | Тип | Описание |
|----|------|----------|
| 1 | single | одиночный снаряд по центру |
| 2 | double | двойной параллельный залп |
| 3 | fan    | тройной веер, ±15° |
| 4 | laser  | непрерывный плазменный луч, DPS |

### Ракетный комплекс
- Автоспавн по таймеру (cooldown из конфига).
- Ур. 1: 1 самонаводящаяся ракета в ближайшего врага.
- Ур. 2: залп из 3 ракет со сплэш-уроном по области.
- Чередование апгрейдов: чётные внутриигровые уровни качают пушку, нечётные — ракеты (авто-апгрейд).

### Внутриигровой XP
- Орбы опыта выпадают из ворот-мишеней и врагов. Разлёт смещён в сторону корабля
  (`towardPlayerBias`), так что дроп сам идёт к игроку, а не рассыпается по экрану.
- Магнит: базовый радиус 150, притяжение `magnetPull`, зона подбора `collectRadius` — сбор
  задуман нетребовательным, орбы не должны теряться.
- Орбы плывут вниз вместе со звёздным фоном, но чуть медленнее (`orbs.scrollFactor` от
  `world.runScrollSpeed`) — параллакс отделяет их слой от фона и подносит дроп к игроку.
- Шкала уровня: `orbsToLevel(level) = base * growth^level`.

### Ворота (Gates)
- **Статические**: спавнятся сверху, летят вниз, слегка «дышат» масштабом; пролёт даёт бафф до
  конца забега (+10% урона или +15% скорострельности; тип и значение из конфига). Пролёт
  подтверждается визуально: вспышка, разлёт искр, всплывающая надпись баффа и новое численное
  значение урона. Пройденные ворота сразу исчезают, чтобы их нельзя было спутать с активными.
- **Подвижные ворота-мишени**: движутся синусоидой, имеют HP; при разрушении выбрасывают
  5–10 орбов с разлётом (импульс + затухание, потом магнит).

### Враги и босс
- Волны мобов по конфигу уровня: тип, количество, интервал, HP, урон при столкновении, монеты.
- Элитные мобы: если `HP >= 10 × урон_игрока_в_сек` — плашка `HP: x/max` над врагом.
- Босс в конце уровня: полоса HP вверху экрана, паттерн атаки — залпы снарядов по игроку,
  движение влево-вправо. Победа → экран победы (монеты + чертежи), поражение → экран поражения
  (собранные монеты сохраняются).
- Всплывающие цифры урона (damage popups) при каждом попадании.

### Обучение (первый забег)
Четыре шага, вплетённые в реальный забег; подсказка — панель вверху экрана, чтобы её не закрывал
палец. Пока обучение идёт, волны и обычный спавн ворот придержаны, на поле только то, чему учат.
Каждый шаг сам выдаёт нужный объект и выдаёт заново, если игрок промахнулся:

1. «Веди корабль пальцем» — ждём смещения корабля.
2. «Стрельба автоматическая — сбей врага» — выдаётся дрон.
3. «Пролети сквозь золотые ворота» — выдаются замедленные ворота-бафф.
4. «Разбей мишень и собери сферы» — выдаётся ворота-мишень; шаг закрывается на 2-м уровне.

Факт прохождения хранится в профиле (`tutorialDone`), повторно обучение не показывается.

### Эффекты
Короткоживущие эффекты (вспышки, искры, всплывающие тексты) живут в отдельном пуле и сами
истекают: проход через ворота, разрушение мишени, взрыв врага. В headless-режиме эффекты
регистрируются логически (без вью), поэтому проверяются тестами без рендера.

## Экран Ангара (Meta)

### Прокачка статов (за монеты), Cost = BaseCost × Multiplier^Level
- Health, Main Attack Power, Rocket Attack Power, Magnet Radius, Offline Income (монет/сек, лимит 8ч).

### Флот
- Viper-X (базовый), Dreadnought (+50% HP, −10% скорость), Falcon (−20% кулдаун ракет),
  Plasma Core (+30% урон главного калибра). Разблокировка за чертежи с боссов.

### Экипировка и Merge
- 4 слота: Двигатель, Обшивка, Чип оружия, Радар.
- Редкости: Common → Uncommon → Rare → Epic → Legendary.
- Merge «3 в 1» одинаковых предметов → предмет следующей редкости; Epic/Legendary дают перки
  (крит-урон, отражение урона). Предметы падают с боссов и покупаются за монеты (для прототипа).

### Наглядность урона
- В ангаре и в HUD забега показывается численный урон главного калибра и ракет.
- Прокачал +10% — число выросло (было 100 → стало 110).

## Прототипные упрощения
- Один сектор с настраиваемыми волнами + босс; после победы уровень зацикливается с множителем HP.
- Авто-апгрейд оружия (без карточек выбора).
- Сохранение меты — JSON-файл рядом с игрой (persistent).
- Offline Income начисляется по разнице таймстампов при входе.

## Конфиги (Assets/Configs/*.json)
- `player_base_stats.json` — стартовые статы, стоимость/прирост апгрейдов.
- `ships_config.json` — корабли, модификаторы, цена в чертежах.
- `weapon_evolution.json` — уровни пушки и ракет (тип, урон, скорострельность, скорость снаряда, угол, сплэш).
- `gates_config.json` — статические и подвижные ворота.
- `equipment_and_merge.json` — слоты, редкости, бонусы, перки, правила merge.
- `levels_and_waves.json` — волны, параметры босса, лут.

## Техническая архитектура (кратко, детали в Architecture.md)
- Bootstrap-сцена: CameraActor + актор `Game` со ScriptableComponent `SpaceEvolver.js`.
- Вся игровая логика — JS; C++ мост (`GameJsBridge`) даёт JS: ввод, размер экрана, создание styled-виджетов,
  чтение конфигов, персистентность.
- Слои сцены: фон, игровые объекты, эффекты, HUD (widget drawDepth).
- Тесты: GameTests (headless, логика JS), GameUITests (окно, скриншоты, драг корабля, победа/поражение).
