## 2026-08-11 — свободный выбор, 100 процедурных уровней, страховка заданий

- **Механика выбора** возвращена к свободной (любые плитки в любом порядке); вернулись
  кластерный бонус (max связная компонента по 8-соседству) и множитель длины 1+0.25(L−3).
  Подсказка снова подбирает мультинабор (жадно, дорогие первыми), а не путь.
- **Кампания — 100 уровней**, генерируются детерминированно по индексу
  (`WordFallLevels.Get`): рампа цели (≈250 + 50/10 уровней), ходов (12–16) и льда (3–10);
  задания (3–5) из пула. Слова-задания выбираются из словаря (3–5 букв, только частые
  буквы — обиходная лексика); первое всегда сидится на поле.
- **Новые типы заданий**: `anyWords` (собрать N любых слов) и `wordScore` (слово на X+
  очков) — вдобавок к word/length/powerup/clearIce. При clearIce льда не больше 6.
- **Страховка выполнимости**: после каждого хода/бустера проверяется достижимость
  каждого незакрытого задания; невыполнимое чинится подсевом недостающих букв в
  случайные клетки (без льда и пауэрапов). При свободном выборе собираемость ==
  мультинабор букв → проверки точные и дешёвые (`_AnyWordExists` — первый матч
  префильтра; глобальный кэш счётчиков букв слова `WordDictNeeds`).
- **Бот**: стратегия — молотки как добивание льда (льдин ≤ зарядов или ходы на исходе),
  сборка слов-заданий напрямую, пауэрап-задачи словом точной длины, length-задачи,
  слова около льда для clearIce, иначе самое дорогое слово. Итераций калибровки было
  три: сначала бот проигрывал 64/100 по word2/clearIce-задачам (стратегия), потом
  21/100 по powerup (слова точной длины), после — 2/100 по clearIce (жадные молотки).
  Финально: **300/300 побед** (100 уровней × 3 набора сидов, node).
- Тесты: пересчитан скоринг, разбросанный выбор снова валиден; новые тесты anyWords/
  wordScore/ремонта/валидности и детерминизма генератора; BotCanWinGeneratedLevels
  (уровни 1/50/100 в headless — полный охват node-прогоном). Сюита ужалась со 102 до

## 2026-08-10 (поздняя ночь) — механика цепочек

Смена кор-механики: слово набирается **цепочкой** — первая буква любая, каждая
следующая обязана быть соседом предыдущей по 8 направлениям; случайно разбросанные
буквы больше не собрать.

- **Выбор** (`ToggleSelect`): проверка соседства с последней буквой; клик по дальней
  плитке — `restart`: начинает новое слово с неё (вью гасит перелёты и запускает
  флаер в нулевой слот).
- **Скоринг**: кластерный бонус потерял смысл (цепочка всегда связна) — удалён;
  вместо него усиленный множитель длины 1+0.5(L−3): 4 буквы ×1.5, 5 ×2 … 8 ×3.5.
- **Спавн**: анти-клин переведён с вертикального правила на соседское — если среди
  заполненных 8-соседей клетки ≥2 букв и нет ни одной гласной, тянется гласная;
  у любой согласной есть гласная рядом → цепочки остаются собираемыми.
- **Подсказка**: `FindBestWord` ищет не мультинабор букв, а **путь-цепочку** (DFS с
  visited, джокер матчит любую букву; старт из клеток первой буквы). Отсев по
  счётчикам букв сохранён. Добавлен фильтр длины `FindBestWord(len)` — для
  length-задач. Пауэрапы/бустеры совместимы с механикой без изменений.
- **Баланс**: цели уровней подобраны по боту — 180/250/350 (бот с идеальной
  подсказкой набирал 253–290 / 351–406 / 466–534 при старых 250/350/500 — впритык;
  человеку нужен запас).
- **Тесты**: переписаны под цепочку и новый скоринг (FarTileRestartsSelection,
  DiagonalChainAllowed, ChainScoreUsesLengthMultiplier и др.); главный новый —
  **BotCanWinEveryCampaignLevel**: бот (первым ходом посеянное слово задания → молоток
  по льду без траты хода → length-задачи словами нужной длины → иначе самое дорогое
  слово-цепочка) выигрывает все 3 уровня на сидах 42/7/2026; в node прогнано 5 сидов
  на уровень — 15/15 побед. Ложная граница в тесте подсказки исправлена (база ФАКТ
  9, а не 11). Все сьюты зелёные.
