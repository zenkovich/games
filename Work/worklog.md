### Код
- JS-модель `GameModel.js` (~500 строк): склад с Overflow Conversion, добыча с множителями, заказы с
  таймерами, продажа × множитель населения, слоты/стройка/красота, Affinity (подарки, штраф за
  повторы, свидания, сюжет, баффы), XP/уровень города, JSON-сейв. Грабли: QuickJS не кладёт
  top-level `class`/`const` в глобальный объект и ругается на повторное объявление при втором
  запуске скрипта → `var CT = ...`, `var GameModel = class ...`.
- C++: `Core/GlassField` + `Core/ResourceBall` (физический стакан), `Core/GameModel` (фасад над JS,
  `Call<T>`), `UI/UIKit` (строители виджетов, headless-safe), `UI/Hud`, экраны `Screens/*`,
  `ColorTownGame` (bootstrap-компонент). Грабли: `GetType()` у компонента конфликтует с
  рефлексией → `GetResourceType()`; `String::Format` нет → свой `Decimal()`.
- `Assets/Bootstrap.scn` сгенерирован кодом (тест `BootstrapScene` сохраняет сцену через
  `o2Scene.Save`, файл скопирован из `Bin/mac/TestTemp`). `GameApplication` грузит его, окно 540×960,
  сейв в `ColorTownSave.json`.
- Физика в headless-тестах: `TickFrame` не шагает Box2D — добавил `TickPhysicsFrame` в тест
  (FixedUpdate + PreUpdate/Update/PostUpdate физики).
